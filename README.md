# fwoce-media.github.io

The Fwoce Media website.

**Live at [fwoce-media.github.io](https://fwoce-media.github.io/)**

This repository holds the site itself — there is no application source code
here. It serves the landing page, the app pages, and `app-ads.txt`.

## What is in here

| File | What it is |
|---|---|
| `index.html` | The landing page |
| `app-ads.txt` | Authorised sellers file, required by Google AdMob |
| `apps/` | Logos, icons and badges used by the page |

## Apps

Everything Fwoce Media builds is software for media you already own — nothing
streams from us, and nothing is uploaded.

- **MP3 Rabbit** — an offline music player for Android.
  [App page](https://fwoce-media.github.io/mp3rabbit/)

More listed on the site as they are released.
